Not not game

Each arrow key has a direction, a color, and a shape.

Read the expression and press a key that matches it before time runs out.

  • green → press the green key
  • not red → press any key that isn't red
  • not not up → press up
  • nothing → don't press anything
  • red and blue → press both keys
  • last key → the key you pressed last round
  • missing: red green blue → press the one not listed

Press any arrow key or tap to start

Esc pauses, R restarts. On a phone, tap the four tiles.
